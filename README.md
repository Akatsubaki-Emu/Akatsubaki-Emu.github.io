# Akatsubaki Emu Website

Static website for the Akatsubaki Emu iOS project.

- Home: https://akatsubaki-emu.github.io/
- Official app source: https://akatsubaki-emu.github.io/AltSource.json
- Xthrx's Repo: https://akatsubaki-emu.github.io/altsource/
- Combined catalogue: https://akatsubaki-emu.github.io/altsource/Xthrx%27s%20repo.json
- Feed report: https://akatsubaki-emu.github.io/altsource/xthrx-source-report.json
- Emulator source code: https://github.com/Akatsubaki-Emu/Akatsubaki-Emu

## Files

- `index.html` — project overview and installation links.
- `AltSource.json` — official Akatsubaki Emu app feed.
- `alt/source.json` — PAL-compatible official app feed.
- `altsource/index.html` — Xthrx's Repo landing page.
- `altsource/` — generated combined catalogue and feed-health report.
- `tools/xthrx-alt-source/` — feed list, catalogue builder, tests and documentation.
- `docs/PAGES_SYNC.md` — GitLab-to-GitHub Pages mirror process.

The pages use plain HTML and CSS without a JavaScript framework or external runtime. GitLab `main` is canonical for this website; GitHub Pages is its public mirror. Akatsubaki Emu's application source repository is separate and canonical on GitHub.

## App source maintenance

The official feed must describe a real IPA already present in the website repository or published by the release workflow. Bundle identifiers, versions, build numbers, dates, minimum OS versions, file sizes and checksums must be taken from the actual artifact, not inferred. The combined catalogue includes the official feed as a first-party source alongside the configured community feeds.

The combined catalogue is generated by `tools/xthrx-alt-source/build_xthrx_repo.py` from `tools/xthrx-alt-source/sources.json`. The updater runs through GitHub Actions. See [the updater README](tools/xthrx-alt-source/README.md) for its behaviour and tests.
