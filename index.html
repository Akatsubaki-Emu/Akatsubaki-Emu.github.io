Akatsubaki Emu

An experimental emulation project for iOS, built around a native app and the Kenran Butō hybrid runtime.

In development. Guest operating-system boot and game compatibility are not yet verified on a physical device.

About

Akatsubaki Emu is being developed as an iOS front end for experimental guest execution and emulation. The runtime combines native components with emulation and translation backends. Features and device support remain under active development.

Installation

The nightly IPA is an unsigned development build. Install it through a compatible signing tool, or add the official AltStore source to a supported client. Builds may be incomplete and are not intended for production use.
