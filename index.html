Akatsubaki Emu

An experimental emulation project for iOS. The project is working towards running desktop and console software through a native iOS interface and a hybrid emulation runtime.

In development · Guest boot and game execution are not yet considered complete

About the project

Hybrid runtime

Kenran Butō combines emulation and translation components behind a shared runtime architecture.

iOS development

The app and its supporting tools are developed for Apple's mobile platforms. Device compatibility and runtime support are still being tested.

Project status

Work is ongoing. Builds and source changes are published through the project repository and its Actions workflows.
