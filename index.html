Akatsubaki Emu

A Steam-oriented game library and experimental guest-runtime project for Apple platforms.

Open source · In active development · Unsigned development builds

Latest nightly build

About the project

The app brings together a game-library interface, file import, session configuration and early guest-runtime work. The runtime architecture is called Kenran Butō (絢爛舞踏); it is being developed to combine native components with emulation and translation backends.

The repository also contains exploratory work on guest memory, storage, display, input and executable-file inspection.

Current state

  • Library and file-import flows, with local session configuration.
  • Read-only metadata inspection for Windows PE and Linux ELF files.
  • Guest-memory, block-device, display and input prototypes.
  • An early tvOS interface preview; its launch and settings actions are not functional runtime controls.

This is not yet a working PC emulator. Arbitrary Windows or Linux images do not currently boot through a complete integrated runtime, and Steam game compatibility is not established.

Downloads

Builds are unsigned and require a compatible signing method. A successful package build does not mean the app or guest runtime has been verified on a physical device.
